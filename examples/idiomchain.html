参考答案

  1. 1.有目共睹 → 睹物思人 → 人尽其才 → 才华横溢
  2. 2.视死如归 → 归心似箭 → 箭在弦上 → 上下其手
  3. 3.语重心长 → 长年累月 → 月下老人 → 人杰地灵
  4. 4.忘乎所以 → 以德报怨 → 怨天尤人 → 人尽其才
  5. 5.私心杂念 → 念念不忘 → 忘乎所以 → 以德报怨
  6. 6.山穷水尽 → 尽善尽美 → 美中不足 → 足智多谋
  7. 7.花好月圆 → 圆满成功 → 功成名就 → 就事论事
  8. 8.一举成名 → 名列前茅 → 茅塞顿开 → 开卷有益
  9. 9.目瞪口呆 → 呆若木鸡 → 鸡犬不宁 → 宁死不屈
  10. 10.异想天开 → 开卷有益 → 益寿延年 → 年富力强
  11. 11.平步青云 → 云开见日 → 日新月异 → 异想天开
  12. 12.尽善尽美 → 美中不足 → 足智多谋 → 谋事在人

接龙答案不唯一，只要首尾相接、不重复即可。
